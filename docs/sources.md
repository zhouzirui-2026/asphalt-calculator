# Sources and factual boundaries

Reviewed: 2026-08-18

Author: Asphalt Calculator Editorial Team

## Density default

The calculator starts at **145 lb/ft³** (about **2,323 kg/m³**) and allows the
user to replace it.

- The U.S. Environmental Protection Agency's cleanup-footprint methodology uses
  an approximate asphalt density of 1.95 short tons per cubic yard. That converts
  to about 144.4 lb/ft³, which this calculator rounds to 145 for a visible
  starting value: https://www.epa.gov/sites/production/files/2015-04/documents/methodology_enivro_footprint.pdf
- The Asphalt Institute states that asphalt mixture typically weighs from 142 to
  148 lb/ft³ in place and tells users to calculate volume, multiply by density,
  then divide pounds by 2,000 for short tons:
  https://www.asphaltinstitute.org/engineering/engineering-faqs/

Actual mix density varies. A supplier's job-mix or measured density should
replace the default when available.

## Unit conversions

- NIST defines the international foot as exactly 0.3048 meter and provides the
  relevant SI conversion background:
  https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors
- NIST Handbook 44 gives 1 avoirdupois pound as exactly 0.45359237 kilogram:
  https://www.nist.gov/document/2026-nist-handbook-44-appendix-b
- FHWA conversion tables identify a short ton as 2,000 pounds and distinguish it
  from a metric tonne:
  https://www.fhwa.dot.gov/publications/research/infrastructure/pavements/10065/10065.pdf

## Assumptions that are not sourced facts

- Waste starts at 0%. The user decides whether to add an allowance based on
  supplier guidance, measurement uncertainty, compaction, and project conditions.
- Material price and all driveway cost inputs start at 0. The site publishes no
  fixed national asphalt price.
- The site does not recommend a pavement thickness. The user enters the compacted
  design thickness provided by the project plan, supplier, contractor, or a
  qualified local professional.
- Results are mathematical planning estimates, not engineering designs,
  specifications, bids, or contractor quotes.
