# Asphalt Calculator repository instructions

These rules apply to this repository in addition to `C:\web-new\AGENTS.md`.

## Product boundary

- This is a standalone, English-first calculator site for United States users.
- Keep the product static-first: no accounts, remote database, payments,
  contact form, outbound email service, advertising, or paid API. The documented
  inbound support alias is allowed; it must not receive calculator values
  automatically. Optional GA4 may load only after explicit consent; never send
  calculator values or share-link query parameters.
- Treat every result as a planning estimate. Never imply engineering approval,
  a contractor quote, a nationally fixed price, or professional certification.
- Density, thickness, price, waste, and cost assumptions must be visible and
  user-editable. Cite factual defaults from primary or authoritative sources.

## Architecture and generated files

- `lib/calculations.ts` is the authoritative calculation layer. UI code must not
  duplicate formulas.
- `site-config.mjs` is the authoritative route and site-origin manifest.
- `public/robots.txt` and `public/sitemap.xml` are generated by
  `scripts/generate-site-files.mjs`; run `npm run sync:site` after route changes.
- Keep the pre-release safety gate enabled until the custom domain, HTTPS,
  canonical host, production routes, and analytics consent boundary pass their
  launch checks. Privacy and terms remain noindex after launch.
- Do not add near-duplicate routes for tonnage or blacktop synonyms. Those
  intents belong to `/asphalt-calculator` unless research proves a new workflow.

## Required validation

Before handoff, run:

```powershell
npm run check
npm test
npm run build
npm run audit:site
git diff --check
```

Also run the local route smoke test and verify the two calculator workflows at
desktop and mobile widths. GitHub and Vercel are the approved publication path;
do not submit search engines or touch unrelated domains without authorization.
